# 词芽 WordSpring

面向个人日常英语学习的网页应用。当前提供 AI 英语老师、错句本、分级听力、任务对话、AI 自由对话和中英翻译。

英语老师支持提问与对话纠错；纠错后的表达可保存到错句本，按“还不熟 / 记住了”安排复习。分级听力保留入门、基础、进阶三档，每次联网生成新的短对话和理解题；先听后答，再看字幕与译文。旧版固定听力的完成次数会保留。任务对话提供咖啡店、问路、购物和酒店四个场景，每轮最多五次发言，结束时给一条改进建议。

用 iPhone Safari 打开[网页版](https://longzhuoyue.github.io/EnglishApp/)，可通过“分享 → 添加到主屏幕”使用。错句、听力和任务对话进度保存在本机浏览器；换手机或清除网站数据前，请在页面底部导出备份文本。旧版备份可导入其中仍使用的进度。访问口令不会写入备份。

本地检查：`node check-ai-ui.cjs`、`node check-practice.cjs`、`node check-backup.cjs` 和 `node cloudflare/check.mjs`。错句复习在静态网页中运行；实时听力、AI 功能及短录音转文字使用 Cloudflare 免费服务与每日额度。语音朗读使用设备语音，识别文字不代表发音评分。服务部署说明见 `cloudflare/`。
