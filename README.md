# 词芽 WordSpring

面向个人日常英语学习的网页应用。当前提供知识学习、AI 英语老师、错句本、分级听力、任务对话、AI 自由对话和中英翻译。

英语老师支持提问与对话纠错；纠错后的表达可保存到错句本，按“还不熟 / 记住了”安排复习。分级听力保留入门、基础、进阶三档，每次联网生成新的短对话和理解题；先听后答，再看字幕与译文。旧版固定听力的完成次数会保留。任务对话提供咖啡店、问路、购物和酒店四个场景，每轮最多五次发言，结束时给一条改进建议。

知识学习有四个专项，每次开启新一组时联网让 AI 生成内容：单词每组 5 个词和例句，并避开本机最近记录的已学词；基础语法按 12 个知识点顺序，每组生成 3 题，规则与答案格式由服务端检查；句子翻译每组生成 3 句，可看提示并让 AI 判断自己的表达；阅读理解每次生成一篇短文和 3 道题。生成后还会检查格式和内容；语法题有个别不合格时，先用合格题和 AI 生成的例句补足，不够再生成一次并组合合格题；仍不足才提示手动重试。其他专项未通过检查时自动尝试一次。未完成的一组保存在本机，可继续练习，完成次数和已学词随备份导出。AI 内容仍可能有错误，适合练习时结合“AI 英语老师”核对疑问。

用 iPhone Safari 打开[网页版](https://longzhuoyue.github.io/EnglishApp/)，可通过“分享 → 添加到主屏幕”使用。学习进度保存在本机浏览器；换手机或清除网站数据前，请在页面底部导出备份文本。旧版备份可导入其中仍使用的进度。访问口令不会写入备份。

本地检查：`node check-ai-ui.cjs`、`node check-practice.cjs`、`node check-knowledge.cjs`、`node check-backup.cjs` 和 `node cloudflare/check.mjs`。错句复习在静态网页中运行；实时听力、知识学习接口、AI 功能及短录音转文字使用 Cloudflare 免费服务与每日额度。语音朗读使用设备语音，识别文字不代表发音评分。服务部署说明见 `cloudflare/`。
