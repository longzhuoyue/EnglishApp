# 词芽 WordSpring

面向英语零基础、每天约 30 分钟的个人学习网页。七天试学含五天日常交流新课、两天复习，每课练习表达、听力、跟读、阅读和短句写作。原有 20 词拓展词库仍可使用。

口语专项提供七个场景，每个场景十二句，交替练短句跟读、看中文说英文和情景回答。每句可标记“还不熟”或“说出来了”，难句会在整轮后复练，也可以下次单独练。可以听设备朗读、录音回放，并在浏览器支持时查看语音识别文字。识别文字仅用于核对内容，不是发音评分；旧版 iOS 的主屏幕模式可用录音回放继续练习。

分级听力有入门、基础、进阶三档共九段日常对话。先听英文并回答问题，再看英文字幕和中文意思；支持慢速重听，不消耗 AI 额度。英语老师的纠错结果可保存到错句本，按“还不熟 / 记住了”安排复习。任务对话提供咖啡店、问路、购物和酒店四个目标场景，每轮最多五次发言，结束时给一条改进建议。

用 iPhone Safari 打开 [网页版](https://longzhuoyue.github.io/EnglishApp/)，可以通过“分享 → 添加到主屏幕”使用。学习进度保存在本机浏览器；换手机或清除网站数据前，请在页面底部导出备份文本，其中包含课程、口语专项、词库、错句本、听力和任务对话进度。访问口令不会写入备份文本。

本地检查：`node check.cjs`、`node check-ai-ui.cjs`、`node check-practice.cjs` 和 `node cloudflare/check.mjs`。课程、听力、错句复习与学习进度在静态网页中运行；AI 对话、英语老师、任务对话、中英翻译和短录音转文字通过 Cloudflare 免费服务完成。语音朗读使用设备语音；录音取决于浏览器权限与设备支持。

AI 服务部署说明见 `cloudflare/`。对话、英语老师、任务对话和翻译共用手机本地保存的访问口令与 Cloudflare 每日免费额度。英语老师提供提问解答、例句和对话纠错；翻译可选中译英或英译中。识别出的文字不是发音准确度分数，暂不提供真实发音评分。
