# 词芽 WordSpring

面向英语零基础、每天约 30 分钟的个人学习网页。七天试学含五天日常交流新课、两天复习，每课练习表达、听力、跟读、阅读和短句写作。原有 20 词拓展词库仍可使用。

用 iPhone Safari 打开 [网页版](https://longzhuoyue.github.io/EnglishApp/)，可以通过“分享 → 添加到主屏幕”使用。学习进度保存在本机浏览器；换手机或清除网站数据前，请在页面底部导出备份文本。

本地检查：`node check.cjs`。本项目为纯静态网页，无账号和服务器。语音朗读使用设备语音；录音和语音转文字取决于浏览器权限与设备支持。
